# v0.11.0 誓約天賦計畫（草案，待玩法邊界確認後凍結）

## 已知良好狀態與範圍

- 起點：`9341813601c38a8e59541557b3f46023c0965757`，分支 `v0110-pact-talents`；v0.10.0 驗收與部署已另有紀錄。
- 本批只做 GDD §陸.5 的三階九選天賦，以及佔領局使用元素技能所需的輸入分流。迷霧、先鋒與 3D 地形留在後續批次。
- 使用者已裁定：佔領局開放元素技能；第 3／6／9 分鐘或任一方先達 250／500／750 分時，雙方同時解鎖對應階。
- `CaptureMatchState.Active` 的元素解鎖不能順帶開放除錯用敵牆與砲台按鈕；`Ended` 仍封鎖技能與英雄輸入。

## 對局規則

1. 每階三選一、各方每階只選一次；達成時間或比分任一條件即開放，不需兩者都成立。跨越多個門檻時依 Tier 1→2→3 順序提供選擇，已選擇不重複觸發。停止／重開佔領局清除所選天賦。
2. 選擇盤在畫面右側，佔領倒數與戰鬥持續。觸控抬起後同一幀套用效果，無確認頁或額外動畫等待。選擇觸控由 UI 優先接收，不洩漏到移動、普攻或符印。640×360 下不能直接接在 CAPTURE 鈕下方：右下符印佔用該區；預定盤面為 `x=MatchPanel.X−196`、寬 176，標題 y60～82、三鈕 y84～122／128～166／172～210。按鈕與整盤背景均須攔截觸控；待實際幾何測試確認。
3. 以下數值照 GDD 原文：

   | 階 | 天賦 | 效果與接點 |
   |---|---|---|
   | 1 | 迅影步 | 連續滑步距離 1.4／1.0／0.7 m；既有連鎖窗口與充能速度不變。 |
   | 1 | 堅磐體 | 擊碎敵方石牆後獲得 220 護盾，維持既有護盾時效。 |
   | 1 | 熾火涌 | 水／火／風元素施法冷卻 5→4.25 秒；不改符印技能冷卻。 |
   | 2 | 裂風矢 | 微滑步後下一次命中的普攻沿攻擊方向貫穿；待確認命中範圍。 |
   | 2 | 潮汐引 | 水系技能半徑 3→5 m；不更改其他元素或反應半徑。 |
   | 2 | 碎岩震 | 近戰飛撲命中使目標眩暈 0.5 秒；待確認「飛撲」在目前原型的觸發動作。 |
   | 3 | 地脈狂熱 | 在己方佔領板塊作戰時，全隊傷害 ×1.15；待確認傷害來源判定。 |

## 待裁定的玩法邊界

- 紅方 AI：雙方門檻同時解鎖已確定；紅方是否自動選擇天賦，以及既有 AI 無滑步／元素技能時如何處理需明定。
- 裂風矢／碎岩震：目前普攻是單目標、無「飛撲」標記；需定義滑步後多久有效、傷害、穿透距離和眩暈對象。
- 元素湮滅／地脈狂熱：需定義真實傷害如何與護盾、聖所互動，以及「在己方板塊作戰」判定的角色與時點。

## 接線約束（架構審視）

- 天賦不能直接改場景共用的 `CombatTuning`／`ElementTuning`／`ProjectileTuning`；對局中的加成要走局內覆寫或當次施法參數，結算與重開立即還原。選天賦前後與回單挑都要可觀察原數值。
- `堅磐體` 的 220 護盾若生效，英雄頭頂護盾條的滿值分母也要變成 220；只改實際護盾、不改顯示不算通過。
- `元素湮滅` 不可只掛在既有 AoE 傷害分支：蒸氣與流沙雖是 Combo，但原 AoE 傷害為 0、舊分支會提早返回。Combo 附加傷害必須以獨立路徑處理，且流沙陣營須取新區域陣營。
- UI 選盤背景也要攔截觸控；既有底部元素鈕在 844×390 橫屏落在畫面外，本批 Active 畫面必須重排到玩家能點到的位置。

## 預定實作順序與驗收

以下的 A 已依使用者對時間／比分門檻的裁定凍結；B～D 待上列玩法邊界答覆後補齊精確案例。任何驗收條件凍結後若需更動，先說明原條件問題並取得使用者同意。

- A（2026-09-29 凍結）：純邏輯天賦狀態。
  - A01：時間在 180／360／540 秒前一刻不開放該階，恰達門檻的同一個 `CaptureMatchLogic.Tick` 雙方都開放；只用時間就能開放，不依賴比分。
  - A02：任一方先達 250／500／750 分，同一個 Tick 雙方都開放相應階；只用比分就能開放，不依賴時間。另一方先達亦同。
  - A03：階數只能增加不倒退；若一次跨越多階，兩方各自依 1→2→3 選擇，不能跳階、重選或拿其他階候選；選擇一方不替另一方作選擇。
  - A04：只有 Active 對局能選；新一局兩方的解鎖與選擇全部歸零，Off／Lobby／Ended 不能沿用上一局效果。
  - A05：舊的 V080Seven／V090Nineteen 規則集沒有天賦；本批只影響正式 V0100Sanctuary 規則集，既有計分、勝負與狂怒測試不更動。
- B0（2026-09-29 凍結，依使用者「佔領局開放元素」裁定）：正式佔領局 Active 時藍方可施放水／火／風；敵牆、砲台與紅方元素除錯切換仍鎖住，即使開局前 ELEM 切成紅方也只會施放藍方元素。Ended 與單挑 Active 仍鎖住元素；V080／V090 舊真值表保持原樣。至少有純邏輯閘門測試與 PlayMode 實際施法／除錯鈕隔離測試。
- B1（2026-09-29 凍結，照 GDD 原數值）：
  - B1-01：選迅影步後藍方三段微滑步為 1.4／1.0／0.7 m；沒選維持 1.4／0.9／0.5 m。只改距離，不改 1 秒連鎖窗口、充能或舊單挑模式。
  - B1-02：選堅磐體後藍方近戰擊碎敵方牆獲得 220 護盾、頭頂護盾條以 220 為滿值；中立牆沿用 150，子彈／牆自然消失不給盾，時效仍 2.5 秒。
  - B1-03：選熾火涌後新施放的水／火／風冷卻從 5 秒變 4.25 秒；已開始的冷卻不回溯縮短，符印不變，各技能仍獨立計時。
  - B1-04：選潮汐引後新生成水域半徑從 3 m 變 5 m；既存水域、其他元素與反應半徑不變。
  - B1-05：選極限超頻後充能上限從 3 變 4，第四格照既有 2.5 秒節奏回充、不立即贈送，第四段沿用最後一段距離；若同時選迅影步則第四段為 0.7 m。
  - B1-06：上述加成只在該局 Active 且該方已選時有效；倒地復活保留，結算／退出與下一局還原，不能改共享 tuning 資產。每項以純邏輯或 PlayMode 行為測試驗數值與回退。
- B：九個天賦接入既有戰鬥流程。每個效果有至少一項會失敗於未接線實作的行為測試；組合選擇不互相覆蓋，紅方 AI 依裁定處理。
- C（2026-09-29 凍結，GDD 右側即時三選一）：
  - C01：Active 且藍方有待選階才顯示盤；依 1→2→3 顯示該階三個固定候選及階數，選後立即消失或顯示下一待選階。Lobby／Ended／Off、尚未解鎖、三階選完均不顯示。
  - C02：盤面 `x=MatchPanel.X−196`、寬 176；標題 y60～82、三鈕 y84～122／128～166／172～210。844×390／dpi 0、640×360／dpi 0、1280×720／dpi 320 下三鈕與標題、右上分數／CAPTURE、上中倒數／聖所、左側現有按鈕、右下符印互不相交且全在畫面內。
