# 第三人稱觸控試作規格

2026-10-01使用者授權：「好啊 換看看 畢竟鏡頭位置不同」。已知良好狀態e73e6ce；只改camera-lab分支，不改主工作樹。

## 本輪行為與驗收

1. 俯視維持既有點地移動、點敵攻擊、符印與Mode A/B手勢。第三人稱改左下虛擬搖桿連續移動、右側空白處拖曳連續yaw/pitch，俯仰有限範圍。
2. 左搖桿移動以鏡頭水平朝向換算；轉鏡頭不強迫靜止角色轉身，角色移動／攻擊仍使用既有朝向與碰撞／狀態限制。不改速度、戰鬥數值、牆或地形規則。
3. 第三人稱右側短tap敵人保留既有目標攻擊；右側tap地面不再下點地導航指令。移動或轉視角手勢不得誤觸世界tap、節奏flick或符印。技能／UI優先，手指起始路由固定，跨區不能偷走另一操作。
4. 左搖桿與右視角可雙指同時工作；release/cancel/失焦/觸控消失/切模式/resize/disable/死亡或局狀態禁止輸入時都能清掉持續狀態，不留下卡走或突跳。切回俯視恢复舊操作。
5. 沿用既有New Input System唯一採樣路徑，不另讀裝置、不引入EventSystem、不增加UI region上限。零輸入時維持舊程式行為。
6. 檢查844×390與640×360 CSS視窗及桌面DPR，第三人稱收起與搖桿衝突的舊除錯HUD，鏡頭切換工具保留但不遮角色中心。直式提示橫放。
7. 新增真路由與Unity端到端測試：方向換算和實際位移、放手停止、雙指move/look、UI/符印優先且無世界滲透、tap敵人與tap地面差異、Cancel/切回/resize/失焦、俯仰限制與原俯視回歸。相關EditMode/PlayMode及verify.sh實跑，fresh程式覆審，瀏覽器截圖與互動驗證，最後只更新Pages的camera-lab子目錄並核對版本列。
