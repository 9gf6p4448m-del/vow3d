## 核心體驗

戰術動作競技：玩家靠漂亮的身位與攻防，運用塑牆、元素改變交戰局面，進而拿下領地、改變戰局。

戰鬥本身應值得反覆玩；領地讓交戰有目的；合作拓展解法；對手能理解並破解。

## 已選定方向

| 項目 | 決議 | 尚待設計或驗證 |
|---|---|---|
| 平台 | 手機優先，PC 提供對應操作 | 真實手機手感、跨端公平性；不先承諾同池匹配 |
| 視角 | 俯視為主方案，另試中距離第三人稱 | 同一遭遇比較操作、資訊理解、重玩意願；第一人稱未選定 |
| 滑步 | 可主動滑步，也保留命中後節奏連動 | 充能、距離、限制；延遲命中的武器不能照搬近戰取消後搖時機 |
| 普攻 | 依武器區分命中方式 | 近戰方向範圍、投射預判、地面施法為提案；具體武器尚未定案 |
| 英雄武器 | 每位英雄先固定招牌武器 | 建立鮮明手感後才考慮其他武器搭配 |
| 塑牆 | 人人有基礎塑牆，角色專精造牆、利用牆或破牆 | 技能與專精分工；不只是加厚或增傷 |
| 牆的歸屬 | 各自管理，新牆只替換自己的舊牆 | 個人上限、存續、尺寸、多人戰場密度；取代全隊兩面自動替換方向 |
| 元素 | 個人攻防完整，合作拓展元素組合 | 可辨識、可反制；不要求每位英雄擁有多種元素 |
| 戰略 | 延續地脈爭地、晶塔與先鋒焦點 | 19 板塊先保留，驗證趕路時間、交戰節奏與目標理解 |
| 模式 | 保留 3v3 與 5v5 | 建議先試作 3v3，再設計 5v5 的地圖與資訊密度；不只增加人數 |
| 死亡 | 越到後期越需要謹慎 | 復活等待與回場距離一併衡量，具體秒數未定 |
| 誓約天賦 | 玩法變化為主，形成打法 | 有得有失、對手可辨識；分支與觸發時機未定 |
| 首玩 | 短而有情境的戰鬥開場，可跳過可重玩 | 躲招、反擊、立牆，再逐步引入領地與合作；故事未定 |

- 比較同一場景的俯視與第三人稱。旋轉控制屬比較必要的操作差異，必須記錄。

- 先觀察能否看懂受擊原因、放牆位置與目標，以及是否想再玩；不預設第三人稱較好。
